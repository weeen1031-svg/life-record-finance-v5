# 記帳 V5

純記帳網頁，提供收支、歷史、分析、帳戶、訂閱、預算、分類與備份功能。

## 資料保存

- 收支與設定保存在目前瀏覽器的 IndexedDB／本機儲存，不會上傳到 GitHub，也不會與其他使用者同步。
- 每個人、每個瀏覽器設定檔各自保存資料。清除網站資料或更換瀏覽器前，請先匯出 V5 JSON 備份。
- 要在新裝置使用自己的資料，請從記帳設定匯出備份，再於新網站匯入。朋友首次使用會從空白資料開始。

## GitHub Pages

此專案的正式網址路徑為 `/life-record-finance-v5/`。網站只會在 HTTPS 的 `*.github.io` 網域與此路徑保存記帳資料。
